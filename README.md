# 베베누리 디자인 디렉션

디자이너에게 공유하는 보호자 앱 아이콘·통계 디자인 디렉션입니다.

- index.html: 본문과 현재 화면·참고 이미지 비교
- assets/: 구현 화면과 베이비타임 참고 이미지
- styles.css: 데스크톱·모바일·인쇄 레이아웃
- app.js: 이미지 원본 확대

로컬 확인: python3 -m http.server 9000 --bind 127.0.0.1

Vercel 프로젝트 bebenuri-design에 main 브랜치를 연결합니다. 문서를 수정하고 main에 푸시하면 같은 공유 주소에 반영됩니다.

공유용 저장소이므로 계정 정보나 개인정보를 추가하지 않습니다. 참고 이미지 출처는 본문에 표시합니다.
